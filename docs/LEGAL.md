# Закон и sqliprobe

Коротко: сканировать можно только то, что принадлежит тебе или где у тебя
есть письменное разрешение владельца (договор на пентест, bug bounty
с разрешением на такое тестирование, свой сервер).

- Россия: ст. 272 УК РФ (неправомерный доступ), ст. 274 (нарушение правил
  эксплуатации). "Я просто проверял" не работает как оправдание.
- США/ЕС: CFAA и аналоги — доступ без authorization = преступление.
- Bug bounty: читай scope. SQLi-тесты вне scope = нарушение правил программы.

Что делает автор чтобы тул не стал отмычкой для школоты:
- флаг `--consent` обязателен, без него только парсинг аргументов
- нет эксплуатации (dump таблиц, os-shell) — только детект
- дефолтная задержка между запросами, без агрессивного флуда

Если нашёл дыру на чужом сайте случайно — пиши владельцу, не трогай дальше.
